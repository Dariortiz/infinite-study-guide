Capstones & exit criteria

A finished route ends in an artifact you can run and a statement you can defend.

Optional-study contract

  1. Name at most two selected tracks.
  2. Attach parent-guide completion evidence.
  3. Define a concrete artifact and stopping condition.
  4. Confirm that deferring every X-guide leaves the core curriculum complete.

Readiness audit capstone

  1. For each of XCP, XSP, XDS, and XFD, name its real parent-spine guide or guides: SRC/ARC, STO/ANA, DYN/DSZ, or the G1–G4 foundations sequence.
  2. Reproduce one theorem or exit artifact from each named parent to certify it as actually complete, not merely familiar.
  3. Reject any X-guide whose parent evidence is missing, and record why.
  4. Certify the deferred set: confirm the core curriculum stays complete with every X-guide deferred.

Placement loop

  • Check: confirm the parent-spine guide is marked complete, not merely opened.
  • Evidence: reproduce one theorem or exit artifact from that parent guide.
  • Defer: if evidence is missing, defer the X-guide and record the gap.
  • Bridge: for a guide marked ready, write the one-line parent-to-X-guide dependency before opening it.

Minimum readiness portfolio

  • A written stop rule capping the number of active X-guide tracks (Module 00).
  • Parent-theorem-and-artifact evidence attached for every candidate track (Module 01).
  • A prerequisite dependency DAG with no optional-to-core inversion (Module 02).
  • One readiness memo per selected X-guide, each with named parent-spine evidence (Module 03).
  • One bridge note applying an optional method back to an existing core artifact (Module 04).

This appendix does not teach compression, advanced processes, global dynamics, or graduate foundations itself — that material lives in the XCP, XSP, XDS, and XFD guides it gates. Its only job is confirming the SRC/ARC, STO/ANA, DYN/DSZ, and G1–G4 spines are actually done before any of those four open.
