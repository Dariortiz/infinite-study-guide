Placement & Diagnostics

Skip material only when you can prove or build the checkpoint unaided; familiarity with vocabulary is not placement.

Andrew Sutherland · MIT OpenCourseWare · official assignments

Tests elementary congruences, arithmetic functions, quadratic residues, and Diophantine proof fluency at the right entry level.

After reading: In 120 minutes attempt one problem each on congruences, orders, reciprocity, and continued fractions; score proof completeness, not answers.
Read
SageMath Coding Theory and Lattices reference
SageMath · official documentation · build diagnostic

Checks whether finite-field linear algebra and exact integer computation are usable tools rather than remembered course names.

After reading: Without copying an example, construct GF(2^4), encode a small linear code, compute a lattice determinant, and verify every result independently.

MODULE 03

Guide Readiness

Use theorem-sized gates: NUM begins with reciprocity and ideals, LAT with convex bodies and duals, COD with distance bounds and finite fields.

NUM readiness gate
G10 Number Theory · internal guide

NUM is ready when elementary proofs are live and abstract algebra is sufficient for rings, ideals, and field extensions.

After reading: Prove CRT and quadratic reciprocity's statement-level consequences; compute the ring of integers in one quadratic example. If either fails, start at NUM Module 0.
Read
LAT readiness gate
G11 Lattices as Mathematics · internal guide

LAT requires determinants, dual spaces, Fourier transforms, and compactness/measure language before homogeneous dynamics.

After reading: Derive the covolume under a basis change, compute a dual lattice, and state Poisson summation for Schwartz functions; route gaps to ALG or ANA.
Read
COD readiness gate
G12 Channel Coding · internal guide

COD requires finite-field linear algebra and probability but not prior cryptography or source coding.

After reading: Construct a parity-check matrix, compute minimum distance for a tiny code, and derive a BSC likelihood metric; route gaps to ALG or PRB.
Read
Exit artifact: Pass one readiness gate per intended guide and record a remediation decision for every failed gate.
MODULE 04

Cross-Bundle Bridges

Return to existing crypto and information guides only after learning the mathematical input; pointers prevent duplicated schemes and protocols.

LAT → PQC and FHE
Existing Mathematical Privacy campus · PQC/FHE pointers

Minkowski, dual lattices, Gaussians, and LLL live in LAT; SIS/LWE reductions, schemes, parameters, and implementation live in PQC/FHE.

After reading: Follow one LAT theorem into PQC or FHE and write the exact interface: hypothesis, imported conclusion, and cryptographic use.
Read
COD → ZKP and Consensus & Settlement
Existing ZKP and blockchain guides · outbound pointers

Reed–Solomon distance supports FRI, while erasure codes support data availability; proof systems and adversarial sampling stay in their destination guides.

After reading: Choose FRI or data availability and separate the coding theorem from the protocol soundness or availability argument.
Read
COD ↔ SRC: channel coding is not source coding
G13 Source Coding · cross-campus pointer

Both use entropy and typicality, but COD adds redundancy against channel noise while SRC removes redundancy from a source.

After reading: For one Bernoulli model, write side-by-side operational problems, rates, converses, and artifacts for source and channel coding.
Read

Capstones & exit criteria

A finished route ends in an artifact you can run and a statement you can defend.

Arithmetic route contract

  1. Name your depth and starting module in NUM, LAT, and COD.
  2. Attach proof or code evidence for every prerequisite and module you skip.
  3. Schedule repairs through PRE/FND rather than duplicating them inside Arithmetic.
  4. Name the first artifact and exit criterion for each guide you will take.

Boundary defense

  1. Explain why homogeneous dynamics belongs in LAT rather than DSZ.
  2. Explain why LWE and FHE schemes remain in their existing crypto guides.
  3. Explain why Reed–Solomon algebra is in COD while FRI is in ZKP.
  4. Explain why channel coding and source coding remain separate guides.
