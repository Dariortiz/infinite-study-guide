Darío's IFA APPENDIX

Placement, prerequisites, and readiness for INF.

Not a lecture course: five modules of placement diagnostics, a prerequisite map into the existing PRE guide, per-guide readiness checks for SRC, ARC, and SCX, and bridges to COD (channel coding) and Session/E2E (AEAD) so this appendix doesn't reteach either. The bilingual diagnostics in Module 01 use Tecnun's and Óscar Ciordia's Spanish-language source-coding lectures alongside PRE's own checks; passing them is what tells you whether to start SRC at entropy rate or skip straight to universal coding.

diagnostic → gap → PRE unit
gap → SRC | ARC | SCX entry module
Kraft's inequality, stationary law, bit packing (checked here)

This appendix doesn't teach entropy coding, codecs, or record-layer cryptography — it only checks whether you can already do the specific things SRC, ARC, and SCX assume: prove Kraft's inequality, compute a Markov stationary distribution, implement bit packing. Every failed check routes to a PRE unit or a named guide module, never to material duplicated here.

Capstones & exit criteria

A finished route ends in an artifact you can run and a statement you can defend.

Information route contract

  1. Record diagnostic evidence.
  2. Name the first SRC, ARC, and SCX modules you will take.
  3. Separate source coding, channel coding, and cryptographic composition.
  4. Link every missing prerequisite to PRE or an existing guide.

Bilingual readiness capstone

  1. Work both the Tecnun and Óscar Ciordia Spanish-language diagnostics end to end.
  2. Solve each exercise independently before checking the worked solution.
  3. Annotate every entropy, expected-length, and coding-theorem term in English notation.
  4. Note which SRC, ARC, or SCX vocabulary this readiness check actually predicts.

Diagnostic loop

  • Attempt: work each PRE, Tecnun, or Ciordia diagnostic cold, without notes.
  • Identify: name the exact skill gap a failed check reveals — proof, computation, or bilingual notation.
  • Remediate: route the gap to one PRE unit or named guide module; never re-teach it here.
  • Recheck: retake the diagnostic and record the pass with a date.

Minimum placement record

  • A dated diagnostic result for Kraft's inequality, a Markov stationary law, and bit packing.
  • A prerequisite dependency graph linking every failed check to a PRE unit.
  • A one-page route contract naming the first SRC, ARC, and SCX module you will take.
  • A cross-bundle diagram separating source coding, channel coding (COD), and Session/E2E composition.

Exit criteria

Diagnostics and placement
You can complete the PRE, Tecnun, and Óscar Ciordia diagnostics cold, prove Kraft's inequality, compute a Markov stationary law, and implement bit packing — without reading ahead into SRC's own lectures.
Prerequisite mapping
You can turn every failed diagnostic into a named PRE unit and a concrete exit test, rather than a vague instruction to "review probability."
Guide readiness
You can defend, with diagnostic evidence, which module of SRC, ARC, or SCX you should start in — entropy rate before universality, strings and bit packing before a codec, and authenticated-channel literacy before a compression oracle.
Cross-bundle bridges
You can separate source coding from channel coding and from cryptographic composition, and name COD and Session/E2E as the guides that own the neighboring material instead of re-deriving it here.
Place in the sequence
This appendix diagnoses and routes; it does not teach entropy coding, codec construction, or record-layer security itself. Passing here means starting SRC, ARC, or SCX at the right module, not skipping them.
