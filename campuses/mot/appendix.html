MODULE 03

Guide Readiness

Enter zoos only after their spine concepts can be used without prompting.

Ready for SPZ?
MTA readiness gate · STO → SPZ

The stochastic zoo assumes laws, filtrations, generators, martingales, and weak limits rather than reteaching them.

After reading: Open SPZ only if you can state the characteristic object and a valid simulator for a chain, diffusion, and jump process.
Open SPZ
Ready for DSZ?
MTA readiness gate · DYN → DSZ

The dynamics zoo assumes flows, linearization, Lyapunov stability, bifurcation, and invariant measures.

After reading: Open DSZ only if you can classify a fixed point, justify a trapping region, and distinguish topological from measure-theoretic behavior.
Open DSZ
Ready to trust a simulation?
MTA readiness gate · SIM across all Motion guides

Every Motion artifact needs numerical validation proportional to the claim.

After reading: For one existing notebook, identify discretization, sampling, floating-point, and model error separately.
Open SIM
Exit artifact: Create a readiness matrix for DYN, STO, SPZ, DSZ, and SIM with evidence links to proofs or notebooks.

Capstones & exit criteria

A finished route ends in an artifact you can run and a statement you can defend.

Motion route contract

  1. Attach evidence for every claimed skip.
  2. Choose DYN, STO, or a sequenced dual spine.
  3. Pair theoretical modules with SIM artifacts.
  4. Name zoo modules to defer until readiness gates pass.

Readiness defense

  1. Present one deterministic proof.
  2. Present one stochastic derivation.
  3. Present one reproducible simulation with an error budget.
  4. Defend the next five modules and the modules intentionally skipped.
