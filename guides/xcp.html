Darío's XCP MOOC

Optional paths beyond lossless source coding.

Eight unrelated meanings of "compression," assembled from research talks and primary papers rather than one course: Bouman's rate–distortion lectures and Ballé's learned-codec talk carry lossy coding into neural compression, Collet's Zstandard engineering and Navarro's succinct-structures text move from format design to searchable indexes, and Candès–Wakin's compressed sensing, Slepian–Wolf's distributed source coding, and Li–Vitányi's algorithmic information theory each redefine the word again. None of the eight modules is required by SRC or ARC; this guide only opens once that lossless spine is done.

Three unrelated compression bounds, not one theorem: rate–distortion trades bits for tolerated error, compressed sensing trades measurements for assumed sparsity, and Kolmogorov complexity trades a program's length for what no code can beat on average.

Choose your route

There is no single course covering rate–distortion, learned codecs, succinct structures, compressed sensing, and algorithmic information at once. Bouman and Ballé supply the lossy/neural half, Demaine and Navarro the structural half, and Candès–Wakin, Slepian–Wolf, and Li–Vitányi the three theoretical detours between them.

MODULE 00

Lossy & Rate–Distortion

Move from the SRC theorem statement to transforms, quantization, and perceptual tradeoffs.

Lossy Source Coding and Rate–Distortion Theory
Charles Bouman · Purdue Digital Image Processing I · 51 min

Derives rate–distortion ideas in the image-coding setting used by the module's transform-codec artifact.

After watching: Derive one scalar rate–distortion example, then compare its prediction with an empirical DCT codec sweep.
▶ Watch
Theoretical Foundations of Transform Coding
Vivek Goyal · IEEE Signal Processing Magazine · 2001

Connects transforms, scalar quantization, and coding gain.

After reading: Implement block DCT quantization and sweep rate versus MSE and perceptual artifacts.
Paper
Exit artifact: Build a transform codec and plot empirical rate–distortion curves.
MODULE 01

Neural Codecs

Learn end-to-end rate–distortion optimization only after classical lossy coding.

Learned Image Compression
Jona Ballé · Picture Coding Symposium 2018 · 58 min

A foundational author explains learned transforms, quantization surrogates, and entropy models inside an operational rate–distortion framework.

After watching: Diagram the encoder, entropy model, and decoder, then reproduce one small rate–distortion ablation.
▶ Watch
End-to-end Optimized Image Compression
Ballé, Laparra & Simoncelli · ICLR 2017

The foundational learned-codec paper exposes analysis transforms, quantization surrogates, and entropy models.

After reading: Train on a small disclosed dataset and compare against a classical baseline.
PDF
Exit artifact: Reproduce a small learned image codec and audit its entropy model.
MODULE 02

Production Compressors

Read Zstandard's engineering tradeoffs and RFC 8878's format spec after algorithm families are already understood.

Beyond Zstandard: The Future of Data Compression
Yann Collet · Linux Foundation · 32 min

Zstandard's author explains the engineering constraints and entropy-coding direction behind a production compressor.

After watching: Trace one block through the reference implementation and profile sequence generation versus entropy coding.
▶ Watch
RFC 8878: Zstandard Compression Format
Yann Collet & Murray Kucherawy · IETF · specification

The stable format specification is the right written companion when implementation compatibility matters more than an informal overview.

After reading: Write a frame parser for headers and block boundaries, then test it against files produced by the reference CLI.
Read
Exit artifact: Profile one production codec path and explain ratio/speed choices from source.
MODULE 03

Compressed Sensing

Treat sparse linear measurement as a different meaning of compression.

Measurements vs. Bits: Compressed Sensors and Information Theory
Stanford EE · research colloquium · 76 min

Separates analog measurement complexity from coded bit rate and makes the sparsity assumptions behind compressed sensing explicit.

After watching: Map recovery success over sparsity and measurement count, then explain where a bit budget changes the result.
▶ Watch
An Introduction to Compressive Sampling
Candès & Wakin · IEEE Signal Processing Magazine · 2008

A concise route through sparsity, incoherence, RIP, and ℓ1 recovery.

After reading: Compare ℓ1 and least-squares recovery over sparsity and measurement grids.
Paper
Exit artifact: Recover sparse signals by basis pursuit and map empirical phase transitions.
MODULE 04

Succinct Indexes

Store searchable structure near information-theoretic space.

Succinct Structures I
Erik Demaine · MIT 6.851 · 80 min

Develops rank/select and succinct trees from the word-RAM perspective needed to reason about both space bounds and query time.

After watching: Implement a two-level rank structure and report overhead in bits plus query latency.
▶ Watch
Compact Data Structures — Chapters 4, 8, and 11
Gonzalo Navarro · Cambridge · selected chapters

Provides practical bitvectors, compressed text indexes, and succinct-tree machinery.

After reading: Implement rank/select and report bits per element plus query latency.
Read
Exit artifact: Build rank/select and an FM-index with measured space and query time.
MODULE 05

Delta & Distributed Compression

Exploit related objects, content-defined chunks, or correlated sources.

The Rsync Algorithm
Camilo Aguilar · Papers We Love NYC · 31 min

Walks through rolling checksums, signatures, and remote block matching without relying on the now-unavailable report page.

After watching: Implement signature and match phases, then measure shifted-file transfer size.
▶ Watch
Slepian–Wolf Theorem
Shashank Vatedka · Network Information Theory 2021 · 65 min

Gives a theorem-level derivation of the distributed source-coding region for correlated sources.

After watching: Derive the corner points of the achievable region for a binary correlated-source model.
▶ Watch
Noiseless Coding of Correlated Information Sources
Slepian & Wolf · IEEE TIT · 1973

Gives the distributed source-coding limit without confusing it with ordinary deduplication.

After reading: Draw the achievable rate region and solve one binary correlated-source example.
Paper
Exit artifact: Build a delta-sync prototype and compare fixed and content-defined chunking.
MODULE 06

Integer Codes

Use short universal codes for residuals, gaps, counts, and timestamps.

Golomb and Rice Codes with Examples
Worldmapper · data-compression lesson · 10 min

A compact worked construction makes quotient/remainder parsing concrete before implementation.

After watching: Round-trip Golomb and Rice codes and choose the parameter minimizing length for geometric samples.
▶ Watch
Integer Encoding: Elias and Rice Codes
University of Pisa · Algorithm Engineering notes · Chapter 8

The written companion derives gamma, delta, and Rice lengths and connects parameter choice to source distributions.

After reading: Prove unique decodability for one code and compare empirical redundancy across geometric parameters.
PDF
Exit artifact: Implement Golomb–Rice and Elias codes and select parameters from a source model.
MODULE 07

Algorithmic Information

Go beyond useful prefix complexity into randomness and universal induction.

Kolmogorov Complexity for Meta-Complexity
Simons Institute · research lecture · 61 min

Shows how incompressibility becomes a proof object while keeping computability limitations visible.

After watching: Formalize one incompressibility argument and identify every place uncomputability blocks an algorithm.
▶ Watch
Li–Vitányi — Chapters 4 and 5
Li & Vitányi · Springer · 4th ed.

Extends prefix complexity toward randomness and universal probability.

After reading: Prove one characterization result and state all uncomputability barriers.
Read
Exit artifact: Write a proof portfolio distinguishing Martin-Löf randomness, semimeasures, and practical coding.

Capstones & exit criteria

A finished route ends in an artifact you can run and a statement you can defend.

Compression boundary atlas

  1. Choose three meanings of compression represented here.
  2. For each, state its signal/source model and objective.
  3. Build one reproducible implementation.
  4. Explain why its guarantees do not substitute for lossless universal source coding.

Applied pipeline capstone

  1. Choose two modules whose exit artifacts can chain, such as a transform or learned codec feeding a succinct index, or content-defined chunking feeding a production compressor.
  2. Build the pipeline end to end on one real dataset.
  3. Benchmark ratio, latency, and space against each stage's exit artifact run alone.
  4. State which of the eight meanings of compression each stage actually uses, and where conflating them would be wrong.

Weekly loop

  • Watch: separate the objective function from the implementation trick that achieves it.
  • Derive: work one rate–distortion, RIP, or coding-theorem bound by hand.
  • Build: implement one codec, index, or code from that module's exit artifact.
  • Explain: state which meaning of "compression" the module uses and which of the other seven it is not.

Minimum portfolio

  • Transform codec with an empirical rate–distortion curve (Module 00).
  • Reproduced learned image codec with an entropy-model audit (Module 01).
  • Zstandard frame parser tested against the reference CLI (Module 02).
  • Sparse-signal recovery with a measured phase-transition map (Module 03).
  • Rank/select structure and FM-index with measured space and query time (Module 04).
  • Delta-sync prototype comparing fixed and content-defined chunking (Module 05).
  • Golomb–Rice/Elias implementation with parameters chosen from a source model (Module 06).
  • Incompressibility proof naming every uncomputability barrier it depends on (Module 07).

Exit criteria

Lossy and learned compression
You can derive a rate–distortion tradeoff for a transform codec, implement block DCT quantization from Goyal, and audit a learned codec's encoder, entropy model, and decoder split from Ballé's ICLR paper.
Production compressors and succinct indexes
You can trace one block of the Zstandard reference implementation against RFC 8878, and build a rank/select structure and FM-index near information-theoretic space using Navarro's chapters.
Compressed sensing and distributed compression
You can compare ℓ1 and least-squares sparse recovery using Candès–Wakin's RIP argument, derive the Slepian–Wolf rate region for a correlated binary source, and explain why rolling-checksum delta sync is a third, unrelated way of exploiting correlation.
Integer codes and algorithmic information
You can select Golomb–Rice or Elias parameters from a source distribution, and formalize an incompressibility argument while naming every place uncomputability blocks an algorithm.
Place in the sequence
You can point to where lossless universal source coding continues (the SRC guide) and where dictionaries, contexts, transforms, and practical algorithmic compression continue (the ARC guide), instead of re-deriving either one inside any of these eight optional detours.

Curation policy

Scope: eight independent, non-required detours past lossless source coding — lossy and learned coding, production compressors, compressed sensing, succinct structures, delta and distributed compression, integer codes, and algorithmic information. Entropy rate and lossless source models are the SRC guide; dictionaries, contexts, transforms, and practical bit-level implementation are the ARC guide. Named editions, papers, and specifications only; no unfiltered channel archives.
