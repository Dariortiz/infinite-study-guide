Capstones & exit criteria

A finished route ends in an artifact you can run and a statement you can defend.

Dynamical atlas

  1. Choose four families with genuinely different invariant structure.
  2. Define each state space, evolution rule, and invariant object.
  3. Build one trustworthy visualization per family.
  4. Explain which properties survive perturbation.

Coding an orbit

  1. Choose a map admitting a symbolic description.
  2. Construct or approximate a partition.
  3. Compare orbit growth with word growth and entropy.
  4. Document failures of the coding at boundaries.
