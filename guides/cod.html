Capstones & exit criteria

A finished route ends in an artifact you can run and a statement you can defend.

Decoder laboratory

  1. Choose one algebraic, one trellis, and one graph-based code at comparable rates.
  2. Implement encoding and decoding with reproducible channel simulations.
  3. Measure block and bit error rates with confidence intervals and complexity counters.
  4. Explain each observed waterfall, floor, or failure using distance, state, or graph structure.

One theorem, three applications

  1. Choose Reed–Solomon, Goppa, or erasure-code mathematics.
  2. Prove one central coding theorem and implement a toy decoder or reconstructor.
  3. Map its use to ZKP, PQC, or data availability through the existing guide.
  4. Separate ordinary decoding guarantees from cryptographic or adversarial assumptions.
