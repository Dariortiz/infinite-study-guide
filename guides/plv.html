Capstones & exit criteria

A finished route ends in an artifact you can run and a statement you can defend.

Verified language pipeline

  1. Define a typed source language and executable interpreter.
  2. Lower programs to an explicit IR and implement one optimization.
  3. State safety and semantic-preservation claims.
  4. Use proof assistance, model checking, and SAT/SMT where each is strongest.
