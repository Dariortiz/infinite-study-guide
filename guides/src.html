Source Coding · infinite study guide

Darío's SRC MOOC

Model a source; approach its entropy rate.

Assembled from Cover and Thomas's Elements of Information Theory, NPTEL's Introduction to Information Theory lectures, David MacKay's Cambridge Information Theory course and Information Theory, Inference, and Learning Algorithms, and the founding Ziv–Lempel, Willems–Shtarkov–Tjalkens, and Rissanen papers. The eight modules move from entropy coders and the AEP through Markov sources, universal Lempel–Ziv, and context tree weighting to Kolmogorov complexity, rate–distortion, and finite-block redundancy — the asymptotic theory of why a code works, not the engineering of one. Module 3's Lempel–Ziv is a universality proof; ARC picks up the same algorithm as an implementation problem.

H(X) = -Σ p(x) log p(x)
-1/n log p(X₁ⁿ) → H(𝒳) (AEP)
Σᵢ 2⁻ˡⁱ ≤ 1 (Kraft–McMillan)

Entropy sets the rate a code cannot beat; the AEP turns that single number into a concentration statement about long typical sequences; Kraft–McMillan turns any achievable set of codeword lengths into an actual prefix code. Every module before Kolmogorov complexity narrows one of these facts into a coder that realizes it.

Choose your route

There is no single course that carries a symbol code from Huffman through the AEP, universal Lempel–Ziv, and context tree weighting to Kolmogorov complexity and rate–distortion without changing proof style halfway through. NPTEL's Introduction to Information Theory lectures and Cover–Thomas's Elements of Information Theory supply the asymptotic spine; MacKay's Cambridge lectures and the original Ziv–Lempel, Willems–Shtarkov–Tjalkens, and Rissanen papers carry it into universal and minimax coding.

Codec builder

Capstones & exit criteria

A finished route ends in an artifact you can run and a statement you can defend.

Universal source laboratory

  1. Generate stationary Markov and hidden-state sources.
  2. Implement range, LZ, and CTW pipelines with round-trip tests.
  3. Compare rate, redundancy, memory, and runtime against entropy-rate estimates.
  4. Defend where each asymptotic theorem does and does not predict finite-file behavior.

Theorem-to-bound capstone

  1. Choose one asymptotic theorem from Module 1, 5, or 6 — the AEP, Kolmogorov incompressibility, or the rate–distortion function.
  2. State and prove it, marking every stationarity, ergodicity, or computability assumption it relies on.
  3. Derive the achievable rate or bound it implies for a concrete test source.
  4. Compare that asymptotic claim against the finite-block redundancy you actually measure in Module 7.

Weekly loop

  • Watch: separate the source model from the theorem it justifies.
  • Derive: reprove one bound — Kraft, the AEP, or minimax redundancy — by hand.
  • Build: implement one coder or predictor and round-trip test it.
  • Explain: state which asymptotic guarantee your finite-block result is approximating.

Minimum portfolio

  • Canonical Huffman code plus a finite-precision range coder with round-trip tests.
  • LZ78 or bounded-window LZ77 implementation demonstrating convergence on an ergodic source.
  • Binary CTW implementation compared against fixed-order KT estimators by log loss.
  • Finite-block redundancy benchmark of KT, CTW, and LZ against block size.

Exit criteria

Entropy coders and the AEP
You can derive canonical Huffman and a finite-precision range or arithmetic coder from Kraft's inequality, and state the AEP as a concentration statement about typical sequences rather than a single-symbol entropy bound.
Markov modeling and universal Lempel–Ziv
You can code a source against matched and mismatched conditional models, and explain why LZ77/LZ78 approach the entropy rate asymptotically without ever being told the source's parameters.
Context tree weighting
You can implement the CTW weighted recursion, verify its predictive probabilities sum to one, and compare its log loss against a fixed-order Krichevsky–Trofimov estimator.
Kolmogorov complexity
You can state the counting argument for incompressible strings and explain why no computable compressor can recognize all of them — a limit the finite-block redundancy measurements in Module 7 approach from an operational direction instead.
Rate–distortion and finite-block redundancy
You can derive R(D) for a Bernoulli source under Hamming distortion, and measure excess codelength against block size for KT, CTW, and LZ well enough to say where an asymptotic theorem stops predicting a real file's behavior.
Place in the sequence
This guide proves Lempel–Ziv is asymptotically universal and states the lossy rate–distortion limit; it does not build a production match finder, range coder, or streaming format — that engineering is the ARC guide — and it does not go past the rate–distortion function into lossy-codec depth, which is the XCP guide.
