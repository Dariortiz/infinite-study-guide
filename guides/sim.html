Capstones & exit criteria

A finished route ends in an artifact you can run and a statement you can defend.

Validated simulator

  1. Choose a queue, SDE, or Hamiltonian model.
  2. Implement two independent algorithms.
  3. Validate against an exact quantity or convergence theorem.
  4. Package tests, environment, seeds, and regenerated figures.

Rare-event benchmark

  1. Specify a rare event and a crude baseline.
  2. Derive an importance or splitting strategy.
  3. Compare variance per unit cost.
  4. Explain bias, numerical failure, and reproducibility risks.
